钢琴采样目录
============

本目录已内置标准 88 键采样（A0 – C8，89 个文件，含一个多余的 Db8）。
删除或替换这里的文件都不影响使用：缺哪个音，那个键就退回 Web Audio 合成音。

命名规则
--------
文件名 = 音名 + 八度，两种写法都认：

  升号（推荐）：C4.mp3  Cs4.mp3  D4.mp3  Ds4.mp3  E4.mp3  F4.mp3  Fs4.mp3 ...
  降号（也认）：C4.mp3  Db4.mp3  D4.mp3  Eb4.mp3  E4.mp3  F4.mp3  Gb4.mp3 ...

程序先找升号名（Cs4），找不到再找降号名（Db4），所以两套命名可以混用。
注意是字母 s，不是 #（Windows 文件名里 # 也不方便）。

音域
----
完整 88 键 = A0(21) 到 C8(108)，共 52 个白键 + 36 个黑键。
少放几个没关系，比如只放 C2–C7 也能正常弹，两端自动用合成音补。

格式
----
- 支持 mp3 / ogg / wav / m4a，优先探测 mp3；
- 建议 44.1 kHz、单声道或立体声均可（程序会混成单声道）；
- 单个文件 1–3 秒即可，程序最多保留 1.8 秒并对尾部做 120 ms 淡出，
  所以采样本身带自然衰减最好，不需要额外做 loop；
- 音量不必自己拉满：程序会按 C4 的峰值自动补偿增益。

内存
----
88 个采样全部解码约占 70 MB（浮点音频很占地方），所以运行时只缓存
最近弹过的 26 个音（约 8 MB），其余按需加载、超出淘汰。
打开面板后会从 C4 向两侧空闲预加载，弹到哪儿基本上都已经就绪。

file:// 打开时
--------------
浏览器禁止从 file:// 读取本地音频（CORS），此时整体退回合成音色，
功能不受影响。要听采样请用本地服务器打开（python3 -m http.server）。
